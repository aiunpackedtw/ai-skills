# AI 拆解室｜觀眾贈品 skill

可以直接交給 AI 的 skill。來自 YouTube 頻道「AI 拆解室」。

## test-first-ci

讓 AI 寫程式時自動先寫測試、每次改完都跑測試、用 Git 分支保存進度，並在 GitHub 接好 CI，錯誤上線前就被擋下來。

怎麼用：

- Claude Code：把 `test-first-ci` 資料夾放進專案的 `.claude/skills/`，或個人的 `~/.claude/skills/`。
- 其他 AI 工具：打開 `test-first-ci/SKILL.md`，把內容整段貼給 AI，請它照著做。

示範專案：https://github.com/aiunpackedtw/ai-expense-tracker
